# Learn Linux - Boot.dev

Repositorio personal para apuntes, comandos clave y ejercicios prácticos del curso Learn Linux en Boot.dev.

### 🐧 Desglose del Curso Actual: Learn Linux
Marca cada capítulo a medida que lo vayas dominando en Boot.dev:
- [ ] **Ch 1: The Command Line** — Shells (`bash`, `zsh`), estructura de comandos, argumentos, flags e historial (`echo`, `history`, `clear`). *(📍 Actualmente aquí)*
- [ ] **Ch 2: Filesystems** — Navegación y manipulación del árbol de directorios (`pwd`, `ls`, `cd`, `touch`, `mkdir`, `cp`, `mv`, `rm`, `cat`, `head`, `tail`).
- [ ] **Ch 3: Programs** — Ejecución de binarios, shebang (`#!`), variables de entorno, el `PATH` (`which`, `export`) y manuales (`man`).
- [ ] **Ch 4: Input/Output** — Flujos estándar (`stdin`, `stdout`, `stderr`), redirecciones (`>`, `>>`, `<`), pipes (`|`) y búsqueda/filtrado (`grep`, `wc`, `sort`, `uniq`).
- [ ] **Ch 5: Local CLI** — Configuración del entorno local, gestión de procesos (`ps`, `top`, `kill`) y archivos de configuración (`.bashrc`, `.zshrc`).
- [ ] **Ch 6: Permissions** — Usuarios y grupos (`sudo`, `chown`), permisos de lectura/escritura/ejecución y notación simbólica vs. octal (`chmod`, `755`, `644`).
- [ ] **Ch 7: Editors and Packages** — Editores en terminal (`nano`, `vim`) y gestores de paquetes para instalar software (`apt`, `brew`, `webi`).
