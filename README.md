# Learn Linux - Boot.dev

Repositorio personal para apuntes, comandos clave y ejercicios prácticos del curso Learn Linux en Boot.dev.

## Secciones clave
- Navegación y sistema de archivos (cd, ls, pwd)
- Manipulación de archivos y directorios (touch, mkdir, cp, mv, rm)
- Permisos y usuarios (chmod, chown)
- Pipes, redirecciones y filtros (|, >, grep, cat)
